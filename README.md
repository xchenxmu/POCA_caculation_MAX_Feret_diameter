# POCA_caculation_MAX_Feret_diameter.py
## Description: 
The POCA software itself does not include a built-in function for calculating aggregate diameters. 
Therefore, based on the principle of Feret diameter measurement, we developed a custom code to calculate the maximum Feret diameter of each aggregate, which was used to represent its overall diameter.
## How to use:
### Just simply two steps:
Step 1: export the "locsObjs" file containing the POCA clustering results.
Step 2: set the path and run the code.
